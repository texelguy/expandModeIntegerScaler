# Expand Mode Integer Scaler 
as the name suggests, an integer scaling addon that respects “expand” stretch mode in Godot 4.x 
how it works: it allows the window to resize the resolution, until it finds an integer value to scale up to… 
this is dead-simple as it can be, very lightweight without using any external viewports, this is also my first plugin, so it’s very specific in us
